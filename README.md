# ИКФС: имитационное моделирование производственной системы в AnyLogic

Проект содержит серию лабораторных работ по дисциплине «Индустриальные киберфизические системы».  
Основная тема проекта — моделирование производственного процесса сборки изделия из двух типов деталей, анализ загрузки ресурсов, внутризаводская логистика и декомпозиция модели на отдельных агентов.

## Стек

- AnyLogic Personal Learning Edition
- Process Modeling Library
- Agent-based modeling
- Statechart
- ResourcePool
- Schedule
- Service / Queue / Assembler / Batch / Sink
- Conveyor / MoveTo
- Ports / Connectors
- AnyLogic charts and statistics
